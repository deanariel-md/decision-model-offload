Board-examination questions (Supplementary Note 1). {question}: the question as published, with its own question
sentence; {option}: the options in the published order. The E line, the E entries of the reply schema and Jev's option
E are sent only with questions that have five options. Reply schema: sent as response_format to every chatbot whose
entry in config/models.yaml has structured_outputs: true. Built by src/jevity/categorical.py from
config/arm2_ext.yaml.

### SYSTEM MESSAGE
Answer this medical question, and give the probability that each option is the correct answer, as numbers between 0 and 1 that add up to 1. Always choose one option. Reply with a JSON object with two keys, "choice" (the letter of the option you choose) and "probabilities" (an object with one number for each letter), and nothing else.

### USER MESSAGE (ends with a line break)
{question}

A. {option}
B. {option}
C. {option}
D. {option}
E. {option}

### REPLY SCHEMA
{
  "type": "json_schema",
  "json_schema": {
    "name": "arm2_ext_answer",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "choice": {"type": "string", "enum": ["A", "B", "C", "D", "E"]},
        "probabilities": {
          "type": "object",
          "properties": {
            "A": {"type": "number", "minimum": 0, "maximum": 1},
            "B": {"type": "number", "minimum": 0, "maximum": 1},
            "C": {"type": "number", "minimum": 0, "maximum": 1},
            "D": {"type": "number", "minimum": 0, "maximum": 1},
            "E": {"type": "number", "minimum": 0, "maximum": 1}
          },
          "required": ["A", "B", "C", "D", "E"],
          "additionalProperties": false
        }
      },
      "required": ["choice", "probabilities"],
      "additionalProperties": false
    }
  }
}

### JEV REQUEST BODY
{
  "model": "typesafe/jev-1.13",
  "state": "{question}",
  "questions": {
    "answer": {
      "type": "choice",
      "instructions": "Answer this medical question.",
      "criteria": {"A": "{option}", "B": "{option}", "C": "{option}", "D": "{option}", "E": "{option}"}
    }
  },
  "provider": {"allow_fallbacks": false}
}
