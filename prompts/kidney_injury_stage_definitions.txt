### SYSTEM MESSAGE
Choose the AKI stage that is correct, and give the probability that each AKI stage is correct, as numbers between 0 and 1 that add up to 1. Always choose one AKI stage. Reply with a JSON object with two keys, "stage" (the AKI stage you choose, written exactly as in the list) and "probabilities" (an object with one number for each AKI stage), and nothing else.

### USER MESSAGE (ends with a line break)
Patient:
{record}

Question: By the KDIGO creatinine criteria, what was this patient's highest AKI stage during the first 72 hours in the intensive care unit?

AKI stages:
no AKI: no value from unit admission to 72 hours is 0.3 mg/dL or more above a value in the preceding 48 hours or 1.5 times or more the lowest value in the preceding 7 days, and no dialysis started
stage 1: a value 1.5 times or more but less than 2.0 times the lowest value in the preceding 7 days, or 0.3 mg/dL or more above a value in the preceding 48 hours
stage 2: a value 2.0 times or more but less than 3.0 times the lowest value in the preceding 7 days
stage 3: a value 3.0 times or more the lowest value in the preceding 7 days; or a value of 4.0 mg/dL or more that itself meets the stage 1 rise or ratio; or dialysis started
