Colon cancer stage with structured input, the recommended form, first version (Supplementary Notes 1 and 2). Jev: the
report is the one field of the case, and the four Choice questions go in one request. Chatbots: the system message,
then the report and Jev's four questions written as JSON with two-space indents and Jev's key order; the reply schema
lists each question's options in Jev's order. The stage group is computed in code from the four answers, for every
system. {report}: the pathology report, without leading or trailing white space. Reply schema: sent as response_format
to every chatbot whose entry in config/models.yaml has structured_outputs: true. Built by src/jevity/docuse_staging.py
from config/docuse_staging.yaml (Jev) and by src/jevity/llm_forms.py from Jev's stored request for the same report
(chatbots).

### SYSTEM MESSAGE
For each question, choose the option that is correct, and give the probability that each option is correct, as numbers between 0 and 1 that add up to 1. Always choose one option for each question. Reply with a JSON object with one key for each question ID, each holding an object with two keys, "choice" (the option you choose, written exactly as in the question's criteria) and "probabilities" (an object with one number for each option), and nothing else.
